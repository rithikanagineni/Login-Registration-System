# 🔐 Login & Registration Authentication System

A modern, fully responsive Login and Registration system with real-time form validation, password strength indicator, and complete user authentication flow. Built with HTML5, CSS3, and JavaScript as part of the **ApexPlanet 60-Day Full Stack Web Development Internship (Task 2)**.
